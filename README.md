# FlowLocal

FlowLocal is a free Windows dictation app that runs on your own PC. Hold Ctrl + Win, speak, and let go: your words are typed wherever you were working. The speech model runs locally, so your voice never leaves your computer and no subscription or cloud account is needed.

**[Download FlowLocal for Windows](https://github.com/Vicranius/FlowLocal/releases/latest/download/FlowLocal-Setup.exe)** · [Website](https://vicranius.github.io/FlowLocal/)

## Features

- Works in any app: text goes where your cursor is
- Turkish and English dictation
- Runs offline after the first start
- Uses your graphics card through Vulkan, and falls back to the processor

## Requirements

- Windows 10 or 11, 64-bit
- A graphics card with Vulkan support is recommended; it also runs on the processor, more slowly
- The speech model (0.5–1.7 GB) downloads once on first start

Windows SmartScreen may warn you when you run the installer, because it is not code-signed yet.
